How Prompt Evolution Works

  1. Analyze — Optimizer reads governance metrics, staging approval rates, and activity logs to identify underperforming prompts
  2. Mutate — Generates improved variants using free-tier models (Cerebras/Groq on EC2, or Ollama on ARM)
  3. Validate — Checks syntax, structure, required sections, and tool references before any agent sees the prompt
  4. A/B Test — Runs original vs evolved version across matching agent tasks, tracks success delta
  5. Promote or Reject — Winners replace originals in the archive; losers are logged with failure reasons

Prompt Library

This page serves as the single source for agent prompts. It loads archived prompts from /workspace/prompts/archive.json on every visit.

Archive Format

{ "prompts": [{ "id": "unique-id", "title": "Short descriptive title", "target": "lead|ops-lead|codecraft|...", "category": "kickoff|research|audit|...", "text": "The full prompt text...", "rating": null or 1-5, "result": "Brief note on what happened", "archivedAt": unix_ms, "archivedBy": "owner|lead|ops-lead|...", "tags": ["tag1", "tag2"] }] }

How to Archive a Prompt

  1. Send a prompt to an agent and get great results
  2. Tell the agent: "Archive that prompt to /workspace/prompts/archive.json with title 'X'"
  3. Or: agents proactively archive prompts that achieved one-shot success
  4. Rate archived prompts on this page — ratings are saved back to the JSON
  5. Over time, high-rated prompts become templates for future tasks

The Vision

As agents improve, the best prompts converge toward one-shot execution — give a single prompt, get a complete result. The archive captures what works so the system gets sharper over time. High-rated prompts are the DNA of effective agent tasking.
