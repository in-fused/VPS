How Governance Works

▲ Performance Score

Composite of success rate (40%), quality (30%), token efficiency (20%), and streak bonus (10%). Updates in real-time.

★ Weekly Evaluation

Every 7 days: tasks (25%), staging approvals (30%), streak (15%), efficiency (15%), peer tasks (15%). Champion earns Elite + lead.

▲ Tier Rewards

Tiers unlock workspace, autonomy, and compute. Elite earns Oracle Cloud ARM partition (24 GB). No extra API costs — rewards are resources.

⚠ Anti-Gaming

Staging approvals (30% weight) require owner review — agents can't inflate their own scores. Collusion = team wipe.

Factory Reset wipes all browser state: chat sessions, governance scores, tier progress, champion history, workflows, and settings. Server-side data (OpenClaw conversations, agent activity logs) is not affected. This cannot be undone.

About Mission Control

Mission Control is the primary hub for managing OpenClaw agents, workflows, and teams on in-fused.org. It connects to OpenClaw via a dedicated WebSocket for real-time agent monitoring and control, and to LiteLLM for multi-provider AI model access. The native OpenClaw UI at /openclaw/ is available as a fallback.
