What Is In-Fused?

In-fused.org is a self-hosted autonomous AI agent system running on AWS EC2. It unifies multiple LLM providers (Anthropic, OpenAI, DeepSeek, Google, Groq, Cerebras, Mistral, and a private Ollama instance on Oracle Cloud) behind a single interface with 8 autonomous agents organized into 2 competing teams.

The system operates 24/7 without human intervention. Agents delegate tasks to each other, produce deliverables, run scheduled background jobs, and organize their own work. The owner manages everything from an iPhone.

Request Flow

Internet → Caddy (auto-HTTPS + cookie auth) → routes to Mission Control, OpenClaw, or LiteLLM. Agents communicate via OpenClaw WebSocket RPC. LiteLLM routes to the cheapest available model with automatic fallback on rate limits.

Capabilities

Autonomous 24/7 Operation
Agents run continuously on EC2. Auto-kickoff on restart sends bootstrap directives to both team leads. Inbox-check cron fires every 5 minutes. No human required.
Agent-to-Agent Delegation
Full P2P mesh. Any agent can message any other agent, cross-team or same-team. Leads orchestrate, specialists execute. Tasks flow through the swarm automatically.
Visual Workflow Builder
LiteGraph-powered drag-and-drop workflow editor. 8 node types: Trigger, Agent, Task, Tool, Condition, Output, Loop, Merge. Auto-save, background execution, agent sync.
Staging & Review
Agents stage deliverables as HTML pages. Owner reviews from phone — approve, reject (with feedback for auto-revision), or ignore. All output is mobile-optimized.
Governance & Competition
Per-agent scoring: tasks 25%, approvals 30%, streaks 15%, efficiency 15%, collaboration 15%. Weekly champion earns Elite tier. Automatic lead replacement at 15+ point gap.
Multi-Provider Fallback
LiteLLM routes across 6 free providers before hitting paid APIs. Latency-based routing picks the fastest. Rate-limited providers are auto-cooled for 60s.
Web Scraping
Scrapling sidecar provides TLS-fingerprint-spoofed HTTP fetching. GET endpoint for quick scrape, POST for advanced selectors. Internal Docker network only.
Oracle Cloud ARM
Free 4 OCPU / 24GB RAM server running Ollama with 3 local models. Zero rate limits. Available to all agents for heavy compute, builds, and long-running tasks.
Background Cron Jobs
Agents create server-side cron jobs that persist across restarts. Inbox check (*/5 * * * *), heartbeat (0 */2 * * *), custom scans, and automated workflows.
Prompt Evolution
Prompt Library with starter prompts, archived effective prompts, star ratings, and an evolution system for autonomous prompt refinement based on agent performance.
8 Real Tools
Web Search (SearXNG), Web Scrape (Scrapling), Code Exec, File Read/Write, Shell, API Call, Browser automation. All wired to OpenClaw's tool system.
Mobile-First PWA
Mission Control works as an iPhone PWA. Touch-to-mouse bridge for workflow canvas. iOS safe areas. 44px touch targets. Owner manages entire system from phone via AWS SSM.

Authentication

Single password protects the entire site via Caddy cookie auth:

  • caddy-entrypoint.sh computes base64 token + SHA-256 hash from OPENCLAW_PASSWORD
  • Login page calls GET /auth/verify with Authorization: Basic <token>
  • On success, sets cookie mc_oc=<sha256hash> (24h, SameSite=Lax)
  • All Caddy routes check for the cookie — unauthenticated requests get the login page

Startup Chain

From deploy.sh to autonomous agent operation:

deploy.sh → docker compose up -d → OpenClaw starts → openclaw-entrypoint.sh L1: patch-openclaw-config.js (gateway, auth, tools, models) L2: seed-agent-workspaces.js (7 files × 8 agents) L3: OpenClaw gateway starts (~50s to healthy) L4: Background (45s delay): seed-via-rpc.js → pushes files via RPC auto-kickoff.js → sends directive to both leads L5: Leads execute BOOTSTRAP.md (verify tools, assign work) L6: Autonomy loop (24/7, self-sustaining): */5 inbox-check → pick up tasks → execute → stage

Timing: Config patched at +5s, OpenClaw healthy at +60s, first tasks assigned at +75s, first deliverables staged at ~+15min. The entire chain is idempotent — redeploy = full re-initialization.
